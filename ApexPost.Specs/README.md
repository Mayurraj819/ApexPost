# ApexPost.Specs

Reqnroll business acceptance features using xUnit. Feature files, injected scenario context, bindings and hooks will be implemented in the BDD stage. Generation is configured under obj so generated code is not committed. No feature scenarios are included in this foundation.

See [TESTING-STRATEGY.md](../TESTING-STRATEGY.md) in the solution root. Use explicit Arrange / Act / Assert sections and `Method_Scenario_ExpectedResult` names. Never use production credentials/data or external HTTP.
